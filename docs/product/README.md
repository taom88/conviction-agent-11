# Product documents

These are sanitized repository copies of the v1.3 design documents used to
shape Conviction:

- [`PRD.md`](PRD.md) — product scope, experience principles, feedback loop,
  evaluation plan, privacy boundaries, and definition of done.
- [`ARCHITECTURE_SOURCE.md`](ARCHITECTURE_SOURCE.md) — original system
  architecture and responsibility boundaries.
- [`IMPLEMENTATION_SPEC.md`](IMPLEMENTATION_SPEC.md) — build order, API
  contract, worker safeguards, and acceptance checks.

They describe the product intent at the time they were written. The root
[`README.md`](../../README.md), current source code, and automated tests are the
authority for implementation status. Employer-specific references were removed
from the public copies; no private transcripts, live agent identifiers, or
credentials are included.
